Hi! I'm {{ site.author }}, a PhD student in the Programming Langauges Group at Northwestern University working with Christos Dimoulas and Robby Findler.

Research Interests

I work on improving IDE support for language-oriented programming (LOP) in the context of Racket. In particular, I focus on using macros as not only an extension point for Racket's compiler but also for IDEs supporting Racket. If any of this interests you, or you want to chat about programming languages, please feel free to email me or message me on Twitter.

Highlighted Projects

  • DrRacket Keybinding/Formatting Plugins

    I created a plugin that lets Racket language creators attach information to their macros that is then extracted and used to register language specific keybindings in the DrRacket IDE. These keybindings are written as programs in a domain-specific language I designed for editor behavior. Similarly, with my labmate Shu-Hung You, I worked on a plugin and domain-specific language for attaching auto-formatting instructions to macros which can then be used to automatically format code inside DrRacket.

  • Puzzler

    With Dr. Jeff Ward at Northern Kentucky University (NKU), I designed a domain-specific language for creating 2D puzzle games called Puzzler. The language was implemented on top of Racket and I gave a talk explaining the design of the language at NKU's Celebration for undergraduate research in 2019.
