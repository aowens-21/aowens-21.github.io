Projects I've Worked On

This page contains information and links to projects I've worked on. They are roughly ordered from most recent to least recent.

  • "Scheme" Interpreter in React (link)

    react-scheme is an interpreter for a "Scheme-like" language written using React. It supports basic arithmetic expressions, symbols, and let-expressions with plans to support a more complete implementation of Scheme in the future.

  • Advent of Code 2021 (link)

    My solutions to many of the advent of code problems for 2021, written in Java.

  • DrRacket Keybinding/Formatting Plugins (link1, link2)

    This project is part of my research working with the programming languages research group at Northwestern. I designed a domain-specific language for implementing keybindings for the DrRacket programming environment, the IDE for the Racket programming language. With one of my labmates, Shu-Hung You I also worked on a domain-specific language for generating auto-formatters for programs written in various Racket languages.

  • Cactus Picker (link)

    Cactus Picker is a game I made using C++ and SFML2. The goal of the game is to use the unintuitive control scheme to pick all the spines off a cactus as fast as possible. I did the all the programming, design, art(the best my programmer brain could do), and sound for the game.

  • Puzzler: A Programming Language for Puzzle Game Creation (link)

    Puzzler is a domain-specific language for creating 2D puzzle games, and it was my capstone project during my undergrad. The language is implemented in Racket and is fully documented on the Racket package server. Along with this language I implemented a game called "Free the Chick" in both Puzzler and C++ (with SFML2), to compare the two implementations. The Puzzler version was 10% of the size of the C++ version in terms of lines of code.

  • Advent of Code 2019 (link)

    My solutions to many of the advent of code problems for 2019, written in Racket.

  • Django TODO App (link)

    This was a small todo app I made while trying to learn Django in college.
